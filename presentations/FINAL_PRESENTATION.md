# Final technical presentation

Open `Final_Crowd_Violence_Presentation_20261119.pptx` in PowerPoint.
The deck has 16 main slides and four appendix slides. Allow about 12 to 15
minutes for the main talk and use the appendix for questions.

Keep the PowerPoint file beside the `media` folder. Slides 13 and 14 link to
four separate MP4 files. Open those files directly if the application blocks
local links. The videos are linked, not embedded. Extract the portable ZIP
before opening the deck, or clone/download the repository with the complete
`presentations` folder.

The presentation covers the implemented pipeline, corrected pose experiments,
RGB reference, validation-selected fine-tuning, fixed RWF and Hockey Fight
results, error examples and offline pose runtime. Speaker notes include
explanations and sources. The original Stage 1 deck remains unchanged.

Paper drafting and independent label review remain pending. The results support
discussion of offline clip classification under the saved experimental
protocols. Streaming performance and deployment reliability remain unvalidated.
