# Prepared independent-review pack

Open `index.html` with a reviewer who has not seen the model predictions. Full clips are transcoded to neutral numbered MP4s and shuffled with seed 42. The page contains no supplied labels, class filenames, model scores or outcome categories. Keep `coordinator_mapping.json` away from the reviewer until labeling is finished.

All 40 clips remain unreviewed. The pack is preparation, not completed independent review. The original sample was ten cases per prediction-outcome category, selected by filename; it is an exploratory diagnostic subset, not a random estimate of dataset-wide label accuracy. Exported labels belong to review records and do not overwrite frozen dataset labels.
