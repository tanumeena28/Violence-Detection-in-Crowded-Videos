# Contributing Guidelines

Thank you for your interest in contributing to the Crowd Violence Detection project.

## Code of Conduct
Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

## Development Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/tanumeena28/Violence-Detection-in-Crowded-Videos.git
   cd Violence-Detection-in-Crowded-Videos
   ```
2. Create and activate virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\\Scripts\\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements-verified.txt
   ```
4. Run tests:
   ```bash
   pytest -q
   ```
